Source: *MDGeniusAI – Brand Guideline* (46 pages, Jan 2026). Launchpad is a sub-brand of the
MDGeniusAI master brand, in the same family as PICS, AURA, NOVA and PREP AI: its own mark,
clearly the same ecosystem.

## 1. What the brand asks for

| Area | Guideline | Today in the app |
|---|---|---|
| Mood | Calm, composed, clinically credible, quietly confident | Dark "Web3" glassmorphism, neon cyan/violet, glow animations |
| Surfaces | Light-first: White Smoke `#F3F3F3`, white panels, navy hairlines | Near-black background, translucent glass cards |
| Primary colors | Navy `#082B42`, Steel `#3A607D`, Mist `#97B7C1` | Bright blue `hsl(204 100% 46%)`, cyan, violet |
| Neutrals | White Smoke `#F3F3F3`, Grey `#7F7F7F`, Black `#000000` | Cool grays |
| Type | Space Grotesk (titles, leads, UI); Helvetica (paragraphs, buttons, links) | Inter |
| Gradients | Sparingly, approved primary transitions only, never over text or data | 29 decorative gradients, 11 gradient-text headings |
| Shapes | Alignment node (✦ at hairline crossings), gradient connector, connector outlines, gradient panel, hollow gradient circle, dashed lines | Glow, pulse, bounce |
| Icons | Thin, single-weight line icons in navy, geometric, rounded joints | Lucide icons in mixed colors |
| Voice | Clear, professional, reassuring, thoughtful; no hype, exaggeration, slang | "Highly selective", emoji, exclamation-heavy copy |

## 2. Logo system (delivered)

Files are in `client/public/brand/` and generated by `scripts/brand/build-logos.mjs`
(text is outlined, so no font is needed to display them).

**Construction.** The Launchpad symbol follows the MDGeniusAI submark grid: rounded modular
blocks (unit : gap ≈ 7 : 3, corner radius ≈ ¼ unit), one compound shape with concave joints,
and one free "node" square. Like PICS (P), AURA (a) and NOVA (n), it spells the sub-brand's
initial: an **L**. The node and the top-right block sit on one diagonal, the launch
trajectory. Gradient runs top-right Steel → bottom-left Navy (reversed: White → Mist), as in
the master symbol.

| File | Use |
|---|---|
| `launchpad-logo-{color,reversed,navy,white}.svg` | Primary lockup: symbol + LAUNCHPAD + "AI Startup / Accelerator Program" (matches the sub-brand lockups) |
| `launchpad-logo-compact-*.svg` | Symbol + LAUNCHPAD: app header, emails |
| `launchpad-logo-vertical-*.svg` | Stacked: auth pages, posters, narrow spaces |
| `launchpad-symbol-*.svg` (+ 512px PNG) | Submark: avatars, loaders, small UI |
| `launchpad-app-icon*.svg` | App tile (rounded), maskable (PWA), square (iOS) |
| `../favicon.svg`, `favicon.ico` (16/32/48), `apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable-512.png`, `site.webmanifest` | Browser and device icons |
| `../og-image.png` | 1200×630 social preview |

Variants: **color** on White Smoke/white, **reversed** on navy or the brand gradient, **navy**
and **white** single-color for print, embroidery and low-fidelity use.

Rules carried over from the guideline: clear space = height of the node square (X) on all
sides; minimum width 55px for the full lockup, 12px for the symbol; never skew, recolor
outside the palette, add effects, or redraw.

> **Font note:** the guideline sets sub-brand descriptors in Helvetica. The logo artwork uses
> Space Grotesk Regular instead, because Helvetica's license does not cover embedding its
> outlines in artwork without a commercial license. If MDGeniusAI holds one, regenerate the
> descriptor in Helvetica with the same script.

## 3. Design tokens

Replace the "Web3 Dark Theme" block in `client/src/index.css` (shadcn CSS variables) and the
`fontFamily` section of `tailwind.config.ts`.

| Token | Value | Notes |
|---|---|---|
| `--background` | `#F3F3F3` White Smoke | App canvas |
| `--card`, `--popover` | `#FFFFFF` | Panels sit on the canvas |
| `--foreground` | `#082B42` Navy | 13.2:1 on White Smoke |
| `--primary` / `-foreground` | `#082B42` / `#FFFFFF` | Primary buttons, active nav |
| `--secondary` / `-foreground` | `#E6EEF1` (Mist at ~25%) / `#082B42` | Secondary buttons, chips |
| `--accent` | `#3A607D` Steel | Links, focus, highlights (6.0:1 on White Smoke) |
| `--muted` / `-foreground` | `#EAEAEA` / `#5F6B74` | Muted text darkened from Grey `#7F7F7F`, which is only 3.6:1 on White Smoke (fails WCAG AA for body text) |
| `--border`, `--input` | `#D5DEE2` | Hairlines; navy `#082B42` at 1px for structural rules |
| `--ring` | `#3A607D` | Focus ring |
| `--destructive` | `#B42318` | Not in the palette; needed for errors. Keep muted, never decorative |
| Success / warning | `#2F6B4F` / `#8A5A00` | Same reasoning; status chips only |
| `--radius` | `12px` panels, `8px` controls | The guideline's panels and blocks are softly rounded |
| Shadows | None or `0 1px 2px rgba(8,43,66,.06)` | Depth comes from surfaces and hairlines, not glow |
| Brand gradient | `linear-gradient(135deg, #3A607D, #082B42)` | Hero, auth panel, app icon only |
| Mist panel | `linear-gradient(90deg, #FFFFFF, #97B7C1)` | "Gradient panel" for one feature card per view at most |

Typography (load from Google Fonts: Space Grotesk 400/500/600; Helvetica from the system
stack `Helvetica, "Helvetica Neue", Arial, sans-serif`):

| Role | Font | Size / weight |
|---|---|---|
| Title (h1) | Space Grotesk | 40–48px / 500, tracking −1% |
| Section (h2–h3) | Space Grotesk | 24–28px / 500 |
| Lead | Space Grotesk | 18–20px / 400 |
| UI labels, nav, data | Space Grotesk | 14–15px / 500 |
| Paragraph | Helvetica | 15–16px / 400, line-height 1.55 |
| Button, link | Helvetica | 15px / 400–500; links Steel, underlined on hover |

Dark mode: the brand is light-first. Keep a dark theme only as an option (navy surfaces
`#082B42`/`#0E3550`, Mist text accents); ship light as the default and remove the forced dark
class.

## 4. Brand shapes as UI components

| Guideline asset | Component | Where |
|---|---|---|
| Alignment node + hairlines | `<NodeRule>`: 1px navy line with a ✦ node at intersections | Page headers (title row ruled off like the guideline pages), section dividers |
| Gradient connector | `<ConnectorBadge>` two offset rounded blocks | Stage/step markers in Roadmap and project lifecycle |
| Connector shapes | Outlined rounded paths | Empty states, onboarding illustrations |
| Gradient panel | `<MistPanel>` | One highlighted card per page (next action, current week) |
| Hollow gradient circle | Progress ring | Readiness score, cohort progress |
| Dashed line, any shape | Dashed border | Drop zones (uploads), "not started" states, linking related cards (like the sub-brand diagram) |
| Modular blocks | Skeleton loaders and the page loader, built from the symbol blocks | Loading states |

Icons: keep Lucide (thin, geometric, close to the guideline set) at `strokeWidth={1.5}`, navy
on light, Mist on navy; drop multicolor icon backgrounds.

## 6. Delivery phases

| Phase | Scope | Estimate |
|---|---|---|
| 1. Foundation | Tokens, fonts, favicon/manifest/OG tags in `index.html`, `<Logo>` component, light default | 0.5 day |
| 2. Shell & primitives | Sidebar, header with node rule, buttons, inputs, cards, tabs, badges, tables, dialogs (shadcn `ui/` restyle) | 1 day |
| 3. Brand components | NodeRule, ConnectorBadge, MistPanel, progress ring, dashed drop zone, block loader | 0.5 day |
| 4. Screens | Replace 142 `glass-card` uses, 29 gradients, 11 gradient-text headings, glow/pulse animations; page layouts above | 2–3 days |
| 5. Copy pass | Rewrite UI copy to the tone of voice (no hype, no emoji, no exclamation marks) | 0.5 day |
| 6. QA | Screenshots of every screen at 1440px and 390px, WCAG AA contrast check, keyboard focus, before/after review | 0.5 day |

Each phase ships as its own pull request behind the existing tests, so production never
shows a half-converted mix for long; phases 1–3 can land together.
